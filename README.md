# Meown

Пиксельная игра о котёнке, который готовится к празднику: магазин, дом и мини-игры.

## Разработка

Проект создан на Godot Engine. Основная сцена: scenes/map/WorldMap.tscn.

## Сборка для ОС «Аврора»

Структура GitVerse CI/CD и инструкции по подготовке RPM находятся в [README_AURORA.md](README_AURORA.md).

Перед запуском сборки необходимо подготовить иконки приложения, тестовый или собственный сертификат разработчика и согласовать версию Godot с Aurora OS.
