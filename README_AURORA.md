# Meown — сборка для ОС «Аврора»

В проект добавлена структура GitVerse CI/CD по образцу https://gitverse.ru/pmifi/godot-aurora-build-ci-cd.

## Структура
- .gitverse/workflows/build-rpm.yml — ручной запуск сборки в GitVerse.
- ci/build_rpm.sh — экспорт PCK и упаковка RPM.
- export_presets.cfg — пресет экспорта ресурсов.
- rpm/ — RPM spec и desktop-файл приложения.
- icons/ — размеры иконок для Aurora OS.
- certs/ — место для тестовой или собственной пары сертификатов.

## Перед первой сборкой
1. Добавить PNG-иконки 86, 108, 128 и 172 px в icons/.
2. Подготовить сертификат и закрытый тестовый ключ в certs/. Не размещать личный релизный ключ в публичном репозитории.
3. Согласовать версию Godot для Aurora OS.

Важно: текущий проект Meown настроен на Godot 4.7.x. В исходном шаблоне используется Aurora-форк Godot 4.4.1. Скрипт намеренно останавливает сборку с понятным сообщением, пока совместимость версий не будет решена. Настройки и игровую логику проекта автоматически не понижаем.

Workflow пока запускается вручную (workflow_dispatch), чтобы обычные коммиты разработки не запускали неподготовленную сборку. После подготовки сертификатов, иконок и версии Godot можно включить запуск на каждый push.
