# Сертификаты для Aurora OS

Сборка ожидает файлы regular_key.pem и regular_cert.pem. Для тестирования используйте только тестовую пару из исходного шаблона. Не размещайте личный релизный закрытый ключ в публичном репозитории. Для публикации в магазине потребуется собственный сертификат разработчика.
